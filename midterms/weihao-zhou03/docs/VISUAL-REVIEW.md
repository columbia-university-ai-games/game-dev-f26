# 首次可玩画面 · 视觉与可读性审阅

日期：2026-10-22。审阅者：视觉/UI 设计子 Agent，仅写本文，不改实现。证据为实际浏览器截图 [`screenshots/first-playable.png`](screenshots/first-playable.png)，约 552×1013 的窄窗口，处于出航后的探索初始状态。辅助只读检查 `src/style.css`、`src/main.ts` 和 `src/renderer/sea.ts`；下列视觉判断来自截图，不将代码存在等同于视觉验证。

本轮已看到低模礁石、暖色船灯、深蓝 HUD、青绿品牌标识及显式八方向选择，整体色系一致，没有满屏玻璃卡片。以下四项优先修正；页面截图未覆盖任务选择、实际回波、搏鱼或攻击状态，不能据此宣称这些状态已验收。表现 Agent 正在调整字号，修改后的状态需重新截图。

## 1. 窄屏丢失核心决策信息（优先级高）

**截图证据：**顶栏有剩余 68 步，但看不到任务配额、船体、船上渔获或剩余声标。玩家知道夜晚在流逝，却无法判断下一次作业的收益与止损条件。只读 CSS 也确认 `max-width:650px` 隐藏 `.ship-panel`，而 `.mission-title` 在更早断点已隐藏。

**具体修正：**窄屏不要直接删掉这些信息。在海域上沿或页眉下增加一条普通实底紧凑状态行，例如“目标 0/2 · 船体 3/3 · 声标 3”，渔获或价值按真实公开字段显示。数字仅为布局示意，不能写死。事件日志可以折叠，但最新重要事件仍要有可读摘要。使用一行文字与分隔符即可，无需新增多张卡片。

**复核条件：**552 px 宽、探索和搏鱼时均可读到当前配额、船体、声标、船上渔获与剩余行动；换行不遮挡攻击通道，数据来自同一公开观察。

## 2. 主要操作和规则说明字号过小、对比不足（优先级高）

**截图证据：**“缓行/急行”的主标签已经偏小，“4 单位·声音较低”、空竿代价、声标延迟和底部“一步推进”说明更细更暗。品牌眉题可小，但这些文本是玩家决定行动所需的信息。窄方向盘也更接近精细工具栏，触控时容易选错。

**具体修正：**主要动作中文至少以约 14 px 起步，决策相关说明约 12 px，次要字色提高到可在当前深底上直接读清；不通过整页缩放把桌面内容塞进窄屏。方向键目标优先增加到约 34–40 px，必要时让方向选择横向展开或与动作组轮流显示。正文换行优于缩到 7–9 px。把“空竿消耗一步”“切线放弃当前鱼”等代价保留在动作附近。

**复核条件：**552 px 下无需放大页面即可读到动作代价；键盘焦点可见，箭头有可识别的选中状态。字号提升后单独检查下竿、声标与搏鱼按钮是否截断。

## 3. 装饰海面过于像散布的声学线索（优先级中高）

**截图证据：**整片黑海铺满细碎青蓝亮点，密度高，视觉上类似鱼群信号或漂浮标记；初始场景实际尚没有探测回波。它同时让海面显得近黑，而不像有连续表面的夜海。当前截图中，装饰纹理占用了本应留给声学信息的高对比青绿色。

**具体修正：**大幅降低小亮点的亮度与密度，转向更宽、更缓、低对比的蓝色波带与少量斜向月光。青绿窄线和明确空心范围留给公开声学事件；装饰不使用环形/局部脉冲，也不围绕隐藏实体生成。先提高海面基础靛蓝亮度一点，再谨慎加纹理，不靠更多发光点“丰富画面”。

**复核条件：**对照一张无探测截图和一张新/旧回波共存截图，玩家能立即指出有效线索；装饰与回波在形状、对比和时间行为上都有区别。等待输入不改变回波年龄。

## 4. 窄屏海域有效内容集中在中央，上下空档偏大（优先级中）

**截图证据：**海域从页眉下延伸到操作带，但实际地图边框约位于 y=205–465；上方提示区与下方纹理区占了较多高度。小船在左下很小，三块礁石容易成为第一视觉重心。完整地图没有被裁掉，这是应保留的优点，但当前的空档没有帮助空间决策。

**具体修正：**窄屏海域高度按地图宽高比加简洁边注空间计算，不机械固定为很高的 `dvh`；把剩余空间让给可读操作和紧凑状态行。不要通过放大裁切海湾来解决。船的表现模型和灯光可适度增强辨认度，但不得改变规则位置、碰撞或投竿范围；北向与港口仍需完整可见。

**复核条件：**552 px 下全地图保留，船首朝向易识别；海域边界、船位和方向预览一致。还需另看 1280×720 与宽屏截图，避免把窄屏构图结论直接套到桌面。

## 本轮未验收项

- 未看到真实新/旧回波、声标启动倒计时与寿命，故不评价这些状态已经正确。
- 未看到搏鱼进度、张力、鱼行为与切线动作的最终布局。
- 未看到攻击走廊出现并由合法动作离开的全过程，故不宣称危险预警公平。
- 未操作音频或键盘，不能由截图推断声像精度、键盘可用性或趣味性。
- 这是实施中的首轮反馈，不是学生 gate 审批或独立规则审查。

建议下次截图最少覆盖：修正后的探索窄屏；宽屏海湾；旧回波与新回波共存；搏鱼且有冲撞通道。四种状态足以先检查核心视觉语法，不需要先增加装饰资产。
