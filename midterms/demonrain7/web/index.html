DEVELOPER WORKBENCH

Explore the rules.

Normal mode

Edit values and inspect the full map in a debug session. Changes apply to this session; original resource files stay intact.

Debug mode starts a new game. Pause to make changes, then resume to see the result.

Player & inventory

Original HP is 13; the debug limit is 127. The health bar still tops out at full. Set HP above zero to revive. Potions restore HP to 13. Directions: 0 up, 1 right, 2 down, 3 left. Toggles: 0 off, 1 on.

Toggles & time

Step while paused. More ticks advance the game further per input. Network speed still affects playback speed.

Enemy & projectile values

Action threshold, 0–256: 0 prevents actions; 256 passes every action check. Cooldowns still apply. Base HP affects new objects; damage and points apply immediately.

Spawn & edit objects

The enemy needs enough clear floor space. Click the map to set coordinates.

Full map & tile editor

Debug only: includes information beyond the game screen. Click a tile to select it. The outer boundary is locked.

Green: floorGray: wallOrange: breakable wallYellow: item / doorRed: objectWhite: player

Tiles & presets

Click the map to select a tile.

Place keys, doors, potions, treasure, or breakable walls. Teleporting requires clear floor space unless wall bypass is enabled.

Save a parameter preset

Presets include player, inventory, type values, and toggles. They do not save the map, objects, or game progress. Changes are also written to a local debug log.

Normal mode · Original rules

The game runs in the background on Windows. Browser play has no audio. Pausing or switching tabs stops play; connection speed affects the pace.
