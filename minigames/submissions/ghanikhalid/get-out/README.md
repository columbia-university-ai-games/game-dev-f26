# Get Out: Key Detour

Open index.html in your browser. Move with arrows, WASD, swipe or direction buttons.
The gold ⚿ tile stops you and unlocks the door. Once you leave it, it becomes a
sealed wall (▣), so find another route. Your first move after collecting K cannot reverse your arrival direction. Locked doors stop you like walls.
Undo restores key status; reset starts with the door locked again. Hints use
the same rules. All four levels contain a key and a verified solution.

The editor accepts one K tile. Exchanged legacy boards without K use the original
unlocked-exit rules. Human playtesting is still TODO; see experiment.md.
